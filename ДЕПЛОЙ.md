# Как выложить куранты на GitHub Pages

Папка `site/` — готовый сайт: `index.html` и файлы в `assets/web/` (≈6 МБ).
Если поменяли `kuranty.html`, пересоберите её командой `python build_site.py`.

## Вариант А — через сайт GitHub (без программ)

1. Зарегистрируйтесь или войдите на github.com.
2. Справа вверху «+» → **New repository**.
   - Repository name: `kuranty` (любое латиницей).
   - Видимость: **Public** (бесплатный GitHub Pages работает только с публичными).
   - Галочки README/.gitignore не ставьте. **Create repository**.
3. На странице пустого репозитория нажмите ссылку **uploading an existing file**.
4. Откройте папку `site` в Проводнике, выделите **всё содержимое** (`index.html`, `.nojekyll`, папку `assets`) и перетащите в окно браузера. Дождитесь загрузки 10 файлов → **Commit changes**.
   - Файл `.nojekyll` скрытый: если его не видно, включите в Проводнике «Вид → Показать → Скрытые элементы». Без него сайт тоже заработает.
5. **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → **Save**.
6. Через 1–2 минуты вверху этой страницы появится адрес вида
   `https://ВАШ_ЛОГИН.github.io/kuranty/` — это и есть ссылка для iPhone.

## Вариант Б — через git (репозиторий в `site/` уже подготовлен)

Создайте пустой публичный репозиторий (шаги 1–2 выше), затем в терминале:

```bash
cd C:/Projects/NewYear/site
```
```bash
git remote add origin https://github.com/ВАШ_ЛОГИН/kuranty.git
```
```bash
git push -u origin main
```

Windows попросит войти в GitHub в окне браузера. Затем включите Pages (шаг 5).

Обновление после правок: `python build_site.py`, затем в папке `site`:
`git add -A`, `git commit -m "Обновление"`, `git push`.

## На iPhone и Apple TV

1. Откройте адрес в Safari. Для полного экрана без панелей: «Поделиться» → **На экран «Домой»** и запускайте с иконки.
2. Поверните телефон горизонтально, выключите беззвучный режим.
3. Пункт управления → **Повтор экрана** → Apple TV.
4. Нажмите «Начать» → шестерёнка → **Интернет-радио** → выберите станцию → «Включить радио».
5. Один раз проверьте всё кнопкой «Показать полночь сейчас».

Радио затихает за 3 секунды до перезвона (23:59:32), затем бой, гимн, салют; около 00:04 радио включается снова.
Если поток не играет, вместо него перед курантами прозвучит «В лесу родилась ёлочка».
